# Del Bajo Real Estate — propuesta web

Landing estática de presentación para Del Bajo Real Estate.

## Contenido

- `index.html`: estructura y copy de la landing.
- `styles.css`: sistema visual responsive.
- `script.js`: navegación móvil, animaciones de entrada y barra de progreso.

## Publicación

El proyecto no requiere build ni dependencias. Puede publicarse directamente en GitHub Pages:

1. Entrar a **Settings → Pages**.
2. En **Build and deployment**, elegir `Deploy from a branch`.
3. Seleccionar `main` y carpeta `/ (root)`.

La página es una propuesta visual; textos, imágenes, propiedades y datos de contacto deben aprobarse antes de presentarla como sitio oficial.
